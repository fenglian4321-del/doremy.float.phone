# 私人 Float：任务内手机界面工具

接在原 FloatShell 无障碍服务和工作/私人区当前所选模型循环。默认关闭，浏览器和旧 APK 不能改走 VPS。没有增加 Android manifest 权限；Shizuku 不是此路径依赖。

用户先在本区消息框写任务，再用系统应用选择器选一个应用，核对本机原生授权框。只读默认，允许操作另选。授权仅留原生进程内，绑定空间、应用、任务 SHA256，墙钟和单调时钟均限制十分钟；任务结束、页面离开、停止或撤销后失效。WebView刷新/导航由原生层另行取消旧任务与确认框，不依赖React清理。用户自行启用已有无障碍服务；不会代开系统权限。

`phone_observe_ui` 返回授权应用可见结构，最多128节点/64KiB，明确长度限制和不可信资料。`phone_click_ui`、`phone_input_ui`、`phone_back_ui` 只认最近快照和节点，无坐标、截图、shell、跨应用或模型自行申请权限。密码和凭据页不读取，系统安全/权限页不控制。输入逐次本机确认；风险或未知点击也要确认。

每次操作前以 owner cookie 对固定本站 `phone_lease` 核对服务器原任务仍运行、版本1、phone执行位置、空间和原任务文字摘要；本机确认后再次核对。页面指纹不符或离开所选应用立即停止。操作先持久写入仅元数据的 HMAC 意图，再触发系统动作。结果不确定保留回执且禁止自动重做；手动核对原回执不会再观察或执行。

操作回执区分动作已请求、输入文字读回核对、界面变化，均不代表业务目标完成。实际界面文字只在本页内存和当前所选模型请求里；不写 VPS 工具轮次或本地元数据日志。最终模型回复仍按本区对话保存，可能包含它引用的界面文字。

模型和 native fixture 用例在 `scripts/test-phone-device-tools.mjs`，覆盖三种实际 provider adapter × 工作/私人区、owner租约、task绑定、只读、错误工具/多余作用域、中断、回执丢失和禁止重放。`scripts/check-device-ui.mjs --compile-policy` 检查静态桥约束与独立 JVM 策略。新增用例已在完整候选统一验收中通过；TypeScript、生产构建、Kotlin 与1.0.31/code30 APK构建/签名校验通过。

真实无障碍页面、系统应用选择器/确认覆盖层、自绘应用兼容和安装后签名迁移仍须最终实机验收。此前1.0.30内部 APK 不包含本次设备界面代码；本次1.0.31候选已核对 DEX 包含设备界面和离线提醒桥。
