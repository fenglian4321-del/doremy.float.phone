# Float 1.0.37 使用与部署

首次打开新版 APK，请在原生账号密码框保留勾选“记住此设备登录”。站点成功加载后，Float 用 Android Keystore 中的 AES 密钥加密保存凭据。下次打开时，原生壳对同一 HTTPS 来源、端口和认证域尝试一次保存的登录。密码失效时会回到手动输入。1.0.36 没有保存过密码，升级后可能需要先输入一次。在“设置 → 运行诊断 → APK站点登录”或原生恢复页可忘记保存的账号，当前打开的会话可能继续有效。网页内各服务的独立会话仍由其服务端决定有效期。

打开桌面“心潮”，开启“允许 Float 查看”，点选栏目。固定角色在“人格与锚点”内选择并确认。已有角色卡、聊天和历史锚点保留在原处。角色核心内容变更后需要重新核对绑定。查看、聊天使用状态、角色工具、互动反馈、后台生成、主动回复及离线通知都有对应控制。

| 栏目 | 本版可用操作与来源 | 配置和验收 |
| --- | --- | --- |
| 潮汐 | 从心潮看板读取情绪、清醒状态、疲劳和全部当前驱力，记录某项驱力得到满足 | 显示原引擎返回的维度。查看不请求模型 |
| 身体与脉 | 读取模拟心率和呼吸，设置有时限的模拟偏移 | 取决于 PULSE。手机实测还需核对聊天联动选项 |
| 念头罐 | 查看持久罐的库存与最近抽取句，选中驱力后明确请求续罐 | 完整罐内文字受私密文字配置控制。续罐取决于原服务的模型、提示词和 DRIVE_POOL 配置，可能计费 |
| 思绪池 | 查看闪念、执念数量及服务允许展示的思绪和梦境 | 私密正文关闭时显示元数据。梦境属于模拟材料 |
| 黑匣子 | 绑定角色获准后，经原 MCP 使用 list、read、put、unpin、burn | 需要原服务开启 MCP。人类看板只说明访问范围。模型可在自己的回复中披露内容。客户端模型请求对设备所有者可检查 |

模拟资料与用户生活事实分开。长期记忆的查看、修改继续走原有 Ombre 星图。心潮新增操作复用既有驱力、罐、信箱、人格和日志存储。后台暂停/恢复作用于现有心潮服务的模型生成，恢复时沿用部署配置。服务原有运行周期和部分功能的频率由服务端配置决定。已发出的模型请求可能完成。

## 部署与回退

本版涉及 APK、Float 网页和心潮扩展。请部署端先按现有流程备份角色数据、服务配置和持久卷。心潮扩展放在仓库的 `tools/float-xinchao-integration`。在心潮服务构建目录的副本上运行，以实际的 `xinchao/src` 路径替换下例中的路径。

```sh
python3 tools/float-xinchao-integration/install.py --source /path/to/xinchao/src check
python3 tools/float-xinchao-integration/install.py --source /path/to/xinchao/src apply
python3 tools/float-xinchao-integration/install.py --source /path/to/xinchao/src check
```

最后一次 check 应显示 installed 为 true。安装器核对 20 个公开源码文件，校验当前运行服务入口的原始版本及补丁内容。需要源码取证时，部署端只提供不匹配的源码文件名、Git blob 和版本。请勿提供令牌、用户数据或生产黑匣子正文。

用该构建目录重建心潮镜像，继续挂载原来的状态卷。Float 服务端沿用既有心潮连接，在核对扩展后设置 `FLOAT_XINCHAO_INNER_CONTRACT=float-xinchao-inner/v1-2abe7fa9`，再重建 Float 网页。账户凭据、模型密钥和服务令牌仅配置在原有相应位置。回退时可恢复先前镜像或用安装器的 `restore` 还原入口并重建。控制文件与原角色、信箱、人格、记忆数据保留。旧 APK 不支持记住登录。

接口依据为 [心潮念 4.3.0 固定源码](https://github.com/tianyupaipai-cmd/xinchao-nian/tree/453d5da50f3c7e26d5ba586714a08c507c94d44f/xinchao/src)，扩展与仓库采用 AGPL-3.0。原生密钥使用 [Android Keystore](https://developer.android.com/privacy-and-security/keystore)。

## 本地验证与上线验收

已使用固定版本的真实心潮 Node 服务和隔离测试数据，验证八个栏目、锁信与收件箱、锚点、身体偏移、驱力满足、时间线、同请求去重、手动续罐与暂停后的调用计数。模型响应使用本机测试服务。已核对安装器 apply、restore 及重新应用。登录验证包含原有 63 项来源/导航等检查，以及 20 项加密、篡改、错误密钥与认证域检查。

部署后用同签名 APK 覆盖升级。请在目标手机实际登录一次，完全关闭并再打开 Float，核对保存登录是否生效。随后测试忘记登录、服务端密码变更、固定角色私聊与 Shizuku 打开允许应用。生产 VPS 上的数据、模型计费和实际手机登录需要部署后分别验收。
