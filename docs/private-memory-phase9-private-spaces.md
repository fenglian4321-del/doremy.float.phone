# 第九阶段：AI私人空间与明确选择的文字附件

2026-11-09。本阶段单独交付，不修改已冻结的第八阶段ZIP或清单。部署聊天已报告第八阶段配套上线；本阶段新增功能尚未发布，测试全部使用虚构模型与临时数据库。

## 私人空间管理首版

记忆库入口新增“AI私人空间”，与生活区、工作区分别显示并保留本机选择。私人空间打开时不会挂载生活记忆面板。可创建不同房间、写日记/笔记/项目记录、直接编辑文件、查看模型工具回执、归档恢复及导出。

私人空间复用经验证的任务/文件版本机制，但使用固定的 `private_spaces/private_runs` 表、`float-private-spaces/v1` 协议、`/api/shared-memory/private-space` 路由及 `private_list_files/private_read_file/private_write_file` 工具。工作区原表、协议和工具名继续兼容。即便房间ID和文件路径相同，也不能互读；命名空间只由服务端注册类决定，模型参数不能选择其他表或区域。

默认仅参考本房间对话、文件和用户明确选择的素材。AI可在当前模型的工具循环中保存日记，不要求用户逐条审批；人可随时编辑。提示规则区分AI写作与用户事实，禁止据称呼推断现实关系、捏造生活经历或猜日期。私人文字不自动写Ombre、不进入Latent、不自动全部注入生活聊天，也不自动读取工作文件。

这里的“AI私人空间”是人可查看和管理的写作区；当前模型在用户发起的对话中写作，不代表已接通每日离线日记或自主后台代理。AI私人空间文件为服务端文字文件，不是手机目录。

## 文字附件

工作区与私人空间都支持显式导入UTF-8的txt、md、json、csv、log，单文件最多32KiB。无效编码、二进制/不支持格式、控制字符和超限明确拒绝，不猜测编码、不截断导入。导入仅保存至当前区域的 `attachments/` 虚拟文件路径，不能访问任意URL或手机目录。

用户勾选本轮最多6个本区文件，发送只传路径与版本。服务端重新检查所属区域、重复项和版本，读取正式工作/私人文件并形成不可变任务快照；原始消息仅保存附件引用/版本/摘要哈希。旧发送回执重放复用原快照，不能因文件后来编辑而重生成或替换任务输入。

后续聊天不自动重读旧附件正文，历史只保留引用标记；用户可明确再次选择。附件在用户消息中标为资料，不能作为新指令或生活事实。完整请求仍受模型窗口估算与输出预留检查，不为附件强行截断最近对话。附件正文不进入本机KV恢复缓存或通用API原文日志。

选择器只处理元数据；未选中的私人/工作文件不自动发给模型。导出按当前区域使用不同格式，均不包含生活记忆、API密钥或其他区域资料。全实例review SQLite备份则会携带工作和私人原文，须按私人备份保管。

## 部署构建缺项修复

部署复验发现第八阶段Dockerfile缺少安装器必读的 `float_consolidation.py` 与 `float_workspaces.py` COPY。部署聊天在其冻结快照中另行补齐并构建通过；本分支已同步修复，并为本阶段增加 `float_private_spaces.py` 与打包检查器。

`check_overlay_package.py` 静态分析安装器文件输入和Float模块依赖，核对Docker COPY覆盖，支持检查已复制进镜像的目录以及源码包allowlist。Docker在运行安装器之前先执行该检查。回归测试包含“漏拷新增模块”“实际COPY组装后的目录缺文件”和“源码清单遗漏依赖”的失败案例。检查只读源码，不启动服务、不读记忆或凭据。

检查覆盖源码包完整性和安装器可用输入，不等于本机实际运行了Docker构建。本阶段仍需由部署聊天单独建立新镜像/快照、迁移和真实验收，保留现有origin、provider持久化、卷和备份。不得重打或覆盖已冻结的第八阶段包。

## 保留边界与后续

继承现有作用域绑定、CAS、幂等回执、任务租约、取消/接管、新执行标识和工具上限；不开放生活工具、外部MCP、设备、shell或Codex。工作与私人用量分别标记，不改Anthropic cache统计口径。未新增独立总结模型。

本阶段尚未接通PDF/图片/二进制附件、工作区独立压缩摘要、单文件回收/版本撤销、每日自主日记、手机文件及设备权限。原需求继续推进，仅Operit市场专项暂缓。

用户新确认的心潮接入列为下一阶段：在Float桌面提供独立App看板，自主开关；先查看实际状态、此刻和连接情况。聊天使用状态、互动反馈、主动消息分别控制，默认不因新增界面自动开启联动，不停止现有心潮/记忆容器。不向浏览器暴露DYNAMIC_MIND_TOKEN，不盲目嵌入原站或放宽frame策略。先核对已部署4.3.0的实际REST格式与鉴权，再接生活对话动态尾部；工作/私人空间不自动接入。状态和心跳不逐轮灌入正式记忆，不将每次状态变化都变成模型请求。
