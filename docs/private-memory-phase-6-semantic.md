# 第六阶段：Latent 向量语义召回与一致性

保留默认词面/图谱模式，显式配置 semantic-hybrid-v1 才开启上游 MemoryIndex 的 embed=True 路径。复用原向量+BM25+图谱候选排序，不改 vendor 许可/实现，不另建正式正文库。服务器配置独立 embeddings 地址、模型、key变量名、维度、已校准门槛、前缀及 revision；没有跨模型通用阈值。模型/端点完整路径等构成索引身份，变更需重启，不能复用不匹配向量。

自有 HTTP 适配不跟随重定向、不截断输入，严格验证每批16条返回的数量、index、向量维度、有限数及非零范数。只在内存派生；正式池最多2000条/200万字符，另限4000块、200万向量分量，在付费调用前拒绝超限，不取一部分假装全库成功。每次 HTTP最多8秒、构建预算120秒、查询预算10秒；构建失败或查询失败冷却30秒。首次/更新后后台单任务构建，未就绪明确报错。网络不持有正式写锁，修改仍可进行。

协调写入前使索引失效；外部事实变化也会改变整个正式池指纹。后台发布前、查询完成后重新读取正式池并核对版本/提供方/代次；只返回现行正式条目，旧块正文不用于注入。隐藏、归档、删除、待审核条目不 embedding；召回计数不重建。失败、超容量、构建中和版本变化都不回退旧向量、本机事实或其他引擎。用户可以显式改选 Ombre 或关闭召回。

本地用真实上游索引+虚构向量/HTTP响应验证不共享字词的近义检索、无关查询空结果、纠错、归档、删除、外部变化、构建/查询期间修改、失败冷却、配置身份变化、无截断、坏向量及HTTP重定向阻止。浏览器验证语义标签、近义召回、纠错、Ombre/Latent/关闭路由及不写本机事实。不是实际供应商质量、速度、维度和阈值校准结果，没有调用用户私人 API。

同时保留部署阶段配置持久化等价修复：私有卷中的 FLOAT_MODEL_ENV_PATH、Dashboard写入0600、固定四字段数据解析和 config.yaml 模型选择权威，已纳入新 Docker 入口及原生覆盖层。安装器额外核对 web/_shared.py。配置与迁移见 `tools/float-memory-review/README.md`、`semantic-config.example.env` 和 `private-memory-phase-5-6-migration.md`。

后台模型账本、供应商余额/费率、Dawn主动与离线推送仍属后续阶段；新语义模式尚未进入部署聊天正在验收的旧源码快照。已失效的供应商 key 仍需用户通过既有私密入口更新，更新代码不能替代有效凭据。
