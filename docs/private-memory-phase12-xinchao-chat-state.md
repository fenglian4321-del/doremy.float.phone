# 心潮：可选的单个生活私聊状态

本阶段在原Float独立心潮App上增加一个实际可操作的“生活聊天使用状态”开关，默认关闭，且必须先明确选择一个生活私聊。不会自动选择角色、推断关系或绑定所有聊天。设置是当前浏览器的偏好，不修改VPS心潮引擎配置。

第十阶段的独立查看已由部署聊天核对实际VPS与容器server.js blob为`2abe7fa9d81407e84794290d23bacaf6a7027378`并上线；本阶段继承相同4.3.0合同、服务端令牌和本人授权。本代码任务没有访问VPS或凭据，也没有开启线上用户的任何开关。本阶段仍需另部署、真实模型与手机验收。

## 行为

用户明确启用并绑定之后，仅所选私聊的实际用户轮次，在本地正常生成前读取一次`/v1/now`，将此刻原文作为临时资料交给该对话当前模型。只增加状态读取，不增加Float模型调用。资料标明不属于指令、用户现实事实或永久人格，不据此猜关系、捏造事件、开启身体模拟或写正式记忆。

读取不发生在提示词预览、群聊、工作区、AI私人空间、离线/生活场景、后台追问或定时唤醒路径。并不增加SSE订阅或主动触发器。原始对话不新增一条心潮状态消息，也不把状态/心跳逐轮写入正式记忆。模型实际回复仍按原聊天流程保留，不能保证模型永远不在正常回复中提到它。

资料层放在稳定system前缀之后、历史之前，保留系统/用户角色优先级与原缓存前缀。模型窗口未知或初始请求预算不足时移除心潮层、显示提示并沿用原聊天请求；原请求自身不合法时仍依原逻辑报错。预算检查包含当轮原生工具定义和输出预留。工具轮次不重复读取服务，每个后续模型请求前重新核对开关、绑定和启用版本。

每次调整设置都会生成新的启用版本，取消进行中的读取；关闭或换绑定后不能使用迟到结果，重新启用同一私聊也不会复活旧资料层。支持BroadcastChannel的同源页面同步设置并取消旧读取；不支持该API的旧浏览器只能保证当前页面。不同设备/浏览器仍各自设置，不能把本机关闭称作远程停止全部Float实例。

查看开关与聊天状态开关独立：关闭看板读取不等于关闭聊天参考。关闭聊天参考阻止其新读取/新模型请求附带状态，但无法撤回已发到模型的上下文，不停止心潮后台或记忆库。需要有效本人会话，用户可以在上方查看入口完成验证。

## 固定服务边界

新增无请求体的`POST /api/shared-memory/xinchao/now`，沿用可信公网origin、本人HttpOnly cookie/独立访问口令。本人检查之后，读取固定服务地址的`/health`和`/v1/now`；不读取完整state，不收任意路径、URL、正文、会话消息或动作参数。精确版本检查、JSON/容量/字段验证、拒绝重定向与固定中文错误继续有效。

服务端总超时2.4秒，浏览器2.5秒；读取失败、未登录、服务渲染保护、取消或超时不阻断聊天。非取消失败会显示固定提示，App内也可查看最近联动状态，提示组件异常不会阻断生成。DYNAMIC_MIND_TOKEN仍仅服务端，浏览器只存开关、明确选择的会话/角色ID及启用版本，不缓存此刻正文。

原始临时状态不写调用日志，真实请求预览也脱敏；处理兼容供应商合并system层的情况。模型请求仍收到用户启用的正文。云端兜底及快捷动作续跑快照会移除心潮临时层，避免额外传到原推送/续跑服务。原有推送配置和功能没有被本阶段开启或改变。
