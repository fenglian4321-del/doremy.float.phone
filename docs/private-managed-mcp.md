# 受控 MCP：内部候选，尚未部署

工作区与 AI 私人空间复用当前选择的模型及三供应商适配器，按原工具调用 ID 回传结果、连续执行和停止。Codex 不是必经通道。普通消息不增加规划模型。外部工具只在用户明确保存本区授权、选择一个服务并启用本次新消息后参与；结束、停止、换页后关闭本次启用。手机工具、VPS 文件工具与外部 MCP 执行位置互斥，服务端任务固定记录执行位置，旧客户端不能接管或转回 VPS 执行。

## 配置与范围

默认 `FLOAT_MANAGED_MCP_ENABLED=false`，目录读取和页面挂载不会连接外部服务。管理员在服务端设置：

- `FLOAT_MANAGED_MCP_STATE_DIR`：独立私有绝对目录，持久卷保存授权及回执元数据。
- `FLOAT_MANAGED_MCP_LEDGER_KEY`：独立 32–512 字符密钥，不与本人访问凭据或 MCP token 共用。
- `FLOAT_MANAGED_MCP_SERVICES_JSON`：参考 `tools/float-managed-mcp/services.example.json`，最多 8 个服务、每服务 32 个工具，明确工作/私人可用范围、只读属性和固定参数 schema。
- 可选 `FLOAT_MCP_SERVICE_TOKEN_*`：仅服务端读取。URL、token、请求头不下发浏览器或模型；凭据轮换会改变服务 revision，使原授权失效，需重新保存。

配置文件中的 example.invalid 不是可用服务。当前候选仅接固定公网 HTTPS 443、无跳转的 MCP Streamable HTTP，协议固定 2025-06-18，支持 JSON 与受限 SSE 响应；每次初始化、通知 initialized、核对完整工具目录后调用。目录仅支持单页、最多 128 项，远端 schema 必须与管理员声明一致。只支持封闭、有限深度的 JSON Schema 子集及文本结果。未支持 stdio、OAuth、HTTP 本地服务、动态安装脚本、外部写入工具或资源/媒体自动获取。管理员声明只读仍需审查实际服务，程序不能证明第三方不会产生副作用。

传输每次解析 DNS，所有地址必须是允许的公网地址，并固定本次 TLS 连接地址、SNI 与证书验证。不通过通用 URL 代理，不跟随跳转、不自动重试 401/404。服务端发起的 sampling/roots 等请求拒绝，远端 instructions 不作为指令。结果以不可信 tool 资料回传，正文不缓存到回执、KV、追踪或用量；正常最终回复仍按原对话存储，模型可能引用资料。

协议依据：[生命周期](https://modelcontextprotocol.io/specification/2025-06-18/basic/lifecycle)、[传输](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports)、[工具](https://modelcontextprotocol.io/specification/2025-06-18/server/tools)。本实现是上述协议的受限接入范围。

## 取消、回执与维护

请求在任何外部连接前落盘不可重放回执，参数只作带密钥指纹。相同请求 ID 再次提交只返回状态，参数变化拒绝，不重新执行或缓存原结果。中断、超时和未知状态须核对原回执；用户显式清除本机等待标记不会撤销或删除服务端回执。撤销授权、原任务租约失效或其他设备取消会阻止后续模型/工具步骤，已发送请求不能保证第三方撤回。

单区最多 1 个、全局最多 4 个活动调用，外部调用总预算 25 秒。回执最多 4096 条，满额拒绝新请求，不自动删除历史以腾空重放空间。状态文件坏损或残留 state.lock 均停止执行；元数据锁最多等待 1 秒，不自动移除旧锁。管理员应先停止服务、备份和检查未完成请求后维护；不要运行中删锁、回执或更换 ledger key 来恢复操作。容器需持久化并备份整个私有状态目录，不能让多实例使用各自独立的回执目录。

该候选要求配套的新前端与 `float_workspaces.py` / 私人空间后端，不能仅复制 MCP route 上线。所有新聊天和摘要任务均由服务端派生 `executionVersion:1`，明确区分 VPS 与 externalMode；旧缓存客户端没有能力头时不能新建、读取或继续已有任务，需刷新。浏览器在首次模型请求、每次模型往返及手机/MCP 动作前核对服务端执行位置，缺失或不匹配时停止并保留回执，不回退其他执行端。

升级前的任务没有执行位置确认标记，不能判断其旧页面是否执行过手机动作。新客户端可查看这些任务、核对原回执并明确结束；后端拒绝恢复、模型轮次、工具动作与保存新结果。不能根据某台浏览器没有 KV 标记就推断旧任务安全。已完成的历史结果仍可查看，不重做模型或工具。结束旧任务不删除消息或已完成文件。当前 phase15 在线站点、冻结包及历史 Release 保留；依照最新交付约定，不单独上传或部署本阶段。

## 内部验证

`npm run test:managed-mcp` 覆盖真实 Next 路由、网关、持久回执、独立 Node 进程恢复、25 秒超时、全局并发、撤销、凭据轮换、异常状态与协议拒绝。模型测试使用真实三供应商适配器、本人代理与临时 Python SQLite 后端，覆盖工作/私人六条路径、原 ID/signature、丢失 begin/finish、旧客户端拒绝和跨设备取消。390px React 测试覆盖默认关闭、明确授权、手动调用、单次启用、停止和恢复状态，未见横向溢出。94 项后端回归、TypeScript、生产构建与 lint 通过；全库 lint 为 0 errors / 686 既有 warnings。

所有模型、材料及 MCP 均为合成测试。HTTP 测试适配器只在测试中替换 HTTPS 请求，并断言 TLS/SNI/固定 DNS 参数；这不是实际公网 TLS、真实 MCP 服务、真实模型计费或真机验证。截图及日志仅保存在本地内部候选目录，不构成新的阶段交付。
