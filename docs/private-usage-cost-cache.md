# 私人 Float：用量、费用和缓存核对

继续以每次实际 HTTP 请求记账，保留所选 provider/model、配置/会话/轮次标识（调用方提供时）、原因、输入/输出/cache读写及缺失状态。工具结果后的续写是实际后续请求；手动摘要和旧线下模式补提独立标注，不把它们解释成必需规划器。心潮普通互动回报不额外调用分类模型，主动消息仅在新且被允许的 delivery 上调用当前所选模型。

费用没有内置价格或外部自动价格查询。用户可为现有配置的具体 provider/model 填写每百万 Token 的输入/输出费率，选择缓存统一输入价或单独读/写价。页面和 JSON 导出按**当前手填费率回算**已有记录，修改费率也改变历史估算；不是当时价格快照或供应商账单。不同币种分别合计，不做汇率换算。空白单价或缺少输入/输出用量保持未知，明确0才按免费计算。差异缓存价所需细项缺失时也保持未知，不把未知当0。

费用计算对标准化的总输入先减去缓存读/写对应普通输入价，再加对应缓存价，不把细项重复计入输入。Anthropic 标准化总输入已包含 input/cache-read/cache-creation；推理细项不另加一次输出。这里只按接口实际报告的输出口径估算，复杂套餐、长上下文阶梯、图片/音频等单独费用不在此通用模型内。

余额继续仅查询已核对的 DeepSeek 官方固定接口；不将中转密钥发送给假定原厂，不支持的服务保持未知。

缓存验收使用同一配置、模型、预设、角色和工具声明，保留稳定人格/工具前缀，只在后面追加正常消息。通过账本比较两次真实请求的输入和缓存读取量；仅同时报告这两项的请求进入命中率分母。不要为了制造命中插入测试调用或改变用户预设顺序。动态状态、历史、供应商缓存门槛/寿命和路由都会影响结果，静态测试不能证明真实缓存命中或保证降低费用。真实 API 的验收另行采用本人授权的输入，不默认为本地自动化已测过。

`test-usage-cost.mjs` 覆盖无价格/缺失/明确0、缓存不重复计费、币种分开、配置与模型匹配和非法费率；既有 token/ledger/reason 测试继续核对供应商计数与调用原因。
