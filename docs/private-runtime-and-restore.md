# 私人 Float：定时日记与恢复边界

保留原日记功能和设置页。定时生成默认关闭，可选角色和1–720小时的间隔；未选角色按全部角色处理。每个到期角色请求其已绑定的日记API一次，没有新建轮询模型或额外总结模型。账本区分「手动生成日记」「定时写日记」，定时来源标为后台任务，并提供非正文的角色范围标识。

逐个角色在请求前记录尝试时间，断线、关闭、失败或刷新后不会立刻重复未知请求。关闭设置或停止服务会中断当前请求、停止本批后续角色；即使旧响应晚到，也不会保存取消后的日记。已发送到供应商的请求仍可能产生费用。已有日记内容保留。定时服务仍依赖当前客户端运行能力，没有宣称替代系统后台调度。

本地/云端备份继续导出用户内容。工作/私人任务恢复凭据、手机文件/UI和MCP等待标记、心潮本机主动接收/反馈开关与请求标记不随备份转移；恢复旧备份也跳过这些键。覆盖恢复不会替换当前设备已有的任务凭据或本机 opt-in。正常笔记、日记、设置及统计保留原路径。原生授权和原生持久动作回执留在原设备，不能从网页备份重新授权或重放。

`test-device-local-backup.mjs` 覆盖实际导出/恢复函数的 KV、旧 localStorage、原始 AiPhoneKvDB 入口及普通内容保留；`test-diary-timer-control.mjs` 覆盖默认关闭、间隔/角色、请求前预留、关闭/中断和失败不重放。上述用例已在完整候选统一验收中通过，新增代码类型检查和生产构建通过。
