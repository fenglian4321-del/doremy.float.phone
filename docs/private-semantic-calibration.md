# Latent 样本校准工具：内部候选

`tools/float-memory-review/calibrate_semantic.py` 补齐独立 embedding 模型的门槛评估入口。它只读取明确传入的样本 JSON，不打开 Ombre、SQLite、聊天或生产配置文件；不写正式记忆，不切换 Ombre/Latent，不修改现行环境变量或运行中索引。

在仓库根目录运行默认检查，不需要凭据、不联网：

```sh
python tools/float-memory-review/calibrate_semantic.py tools/float-memory-review/semantic-calibration.example.json
```

例子全部是虚构材料，只说明格式。实际质量评估需要人工选定有代表性的可发送样本，明确哪些查询应命中哪些事实、哪些应无答案。每组最多 64 条记忆、64 条查询，文件不超过 256 KiB，单条不超过 4096 字符，派生块最多 128、向量分量最多 200 万；超限拒绝，不截断。调参组与独立留出组各至少 2 条有答案、2 条无答案；禁止重复查询、跨组重复和照抄事实作为查询。最低数量只是格式门槛，不代表样本充分。

实际发送需另行配置 `semantic-config.example.env` 中的独立 embedding 端点、模型、维度、凭据环境变量与查询前缀，并显式使用 `--send-to-configured-provider`。这会把所选样本正文发给对应服务且可能计费；代码开发期间没有执行实际发送。无需先填未知的 HIT_FLOOR，工具只在临时提供方中用零作扫描基线，绝不写回生产：

```sh
python tools/float-memory-review/calibrate_semantic.py /private/approved-samples.json --send-to-configured-provider --report /private/new-calibration-report.json
```

可选报告以独占方式提前保留路径，拒绝覆盖已有报告，避免重跑时先产生费用。失败可能留下空报告，需核对后另选新文件名。POSIX 创建权限为 0600；Windows 文件权限取决于所选私有目录的 ACL。凭据仍只读独立服务端环境变量，不放命令参数、样本、报告或异常正文。

评估使用与 SemanticRecall 相同的上游完整混合检索、topN=20。先建一次块向量、一次批量查询向量，再复用向量和相似度，在 0–1 的 0.01 网格评估；不会给每个门槛重复收费。每批最多 16 条，embedding 总预算 120 秒，总评估预算 180 秒。先在调参组按误召回最少、召回最高、同分门槛较高选择；留出组只验一次，不用它重新调参。

报告仅含配置/样本指纹、数量、接口批次数、聚合精确率/召回率、无答案误召回和候选门槛，不含文本、向量、命中 ID、端点、模型名或密钥。只有两组均无误召回、召回率至少 80%、门槛严格位于 0 与 1 之间时，才给出 `recommendedFloor`；否则为 null，要求检查样本/模型。`sample_supported` 只表示这份小样本支持候选，不是生产质量保证。人工复核后才可将候选填入实际配置并重建索引。

2026-11-10 真实供应商测试发现原 BM25/图谱候选可绕过向量门槛，故 Float 适配层新增 `SemanticCandidateIndex`：保留上游完整混合排序，复用该次查询已算好的余弦，对最终每个候选统一要求 cosine > 已校准 floor，拒绝缺失/非有限相关度，不增加 embedding 请求。校准与运行继承同一个门禁，报告标记 `all-candidates-cosine-v1`；上游 vendored 引擎未修改。测试覆盖词面强但语义弱、图谱扩展、同名未知事实、原排序保留、查询次数、纠错与取消。门槛仍只由调参组选择，留出失败仍拒绝推荐；不修改固定真实样本或放宽通过标准。更换端点、模型、维度、前缀或语料后需要重新评估；真实非私人样本的首次供应商结果已暴露上述缺陷；修复后须由部署端以同一冻结样本重新实测，未通过前不激活生产语义配置。

针对性本地测试使用真实上游索引与合成向量，验证扫描复用、查询前缀、无答案/词面误召回、留出组隔离、错误样本拒绝、默认零网络、报告不覆盖及错误脱敏。该 CLI 不依赖部署，未加入服务端 Docker 自动入口，不能在服务器启动时自动发送生产语料。
