# Float 工作区与记忆星图

2026-11-10 源码进度快照。按用户要求先上传原仓库 `private-custom` 分支。

- 桌面新增独立「工作区」：会话列表、聊天流、底部输入框；文件、附件、上下文与工具保留在抽屉中，支持工作/私人区隔离。
- 桌面新增独立「记忆星图」：复用现有星海与共享记忆接口，读取、编辑、版本冲突、历史和撤销都连接配置的同一 VPS 记忆库；打开页面不会自动切换记忆来源。
- 当前选定模型可在同一任务内组合使用本区文件、明确授权的手机目录/设备界面、管理员配置的 MCP 与已勾选 Float 工具。手机能力仍受系统授权、具体任务和原生确认约束；不能绕过 Android 权限或保证所有应用界面可操作。
- Float 写入或未知副作用动作逐次确认；执行前持久化元数据回执，丢失结果保持待核对，不自动重放。共享记忆修改需要先读取当前版本并逐次确认。
- 手机界面组合调用要求原生桥声明 `composedTasks`；旧安装包会提示升级。当前源码包含对应桥改动，新增功能尚未重新打包为 APK。
